# TP Vue.js — ERRAFIY & SAADEDDINE

Tous les TP disponibles sont regroupés dans [TP-ERRAFIY&SAADEDDINE](TP-ERRAFIY%26SAADEDDINE/). Chaque TP dispose aussi de sa branche dédiée, intégrée à `main`.

- TP1, TP1A, TP1B, TP1C : catalogue et exercices associés.
- TP2 et TP2-suite : liste de personnes et suite du catalogue.
- TP3-taches : gestion de tâches ; TP3-composants : composants et cycle de vie.
- TP4 : routeur et Composition API.
- TP5 : application d'offres d'emploi.
- TP6 : annuaire étudiants.
- TP7 : explorateur de pays.
- TP9 : météo.

Le TP8 n'est pas inclus.

Pour un projet utilisant Vite, entrer dans son dossier, puis lancer `npm ci` (ou `npm install` si aucun fichier de verrouillage n'est fourni) et `npm run dev`. Sous PowerShell, utiliser `npm.cmd` si l'exécution des scripts est bloquée.

Pour le TP9, copier `.env.example` vers `.env` et renseigner sa clé OpenWeatherMap ; ne pas publier `.env`. Les variables `VITE_` sont visibles dans le navigateur et ne constituent pas des secrets côté client.

Le TP7 utilise countries.dev, car l'ancienne API indiquée dans l'énoncé a changé.
